# 🧮 BMI Calculator Project (Age, Height & Weight)

This is a simple and interactive **BMI Calculator** built using HTML, CSS, and JavaScript. The user can select gender and enter their **age, height, and weight**, and the application calculates their BMI and shows the health category.

## 📌 Features

* Takes user input (Age, Height, Weight)
* Calculates BMI instantly
* Displays BMI result with category
* Shows health status:

  * Underweight
  * Normal weight
  * Overweight
  * Obese
* Simple and clean user interface
* Beginner-friendly JavaScript project

## ⚙️ How It Works

User enters:

* Age (years)
* Height (cm or meters)
* Weight (kg)

BMI is calculated using the formula:

BMI = weight / (height × height)

Based on the result, system shows the user’s body condition.
