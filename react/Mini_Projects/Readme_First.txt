# ⚛️ React Mini Projects Collection

This project contains two mini React applications inside a single project:

1. 🎨 Background Color Changer
2. 🔐 Random Password Generator

Only one component can be active at a time using conditional rendering in `App.jsx`.

---

## 🎨 1. Background Color Changer

This project allows users to change the background color of the screen by clicking different color buttons. Each button represents a specific color, and when clicked, the background instantly updates.

### Features:

* Multiple color buttons
* Instant background change
* Simple and interactive UI
* Built with React state management

---

## 🔐 2. Random Password Generator

This project generates strong random passwords in real-time. It continuously creates secure passwords based on random characters.

### Features:

* Random password generation
* Real-time updates
* Strong password output
* Simple UI for user interaction

---

## ⚙️ How to Run Project

```bash
npm install
npm run dev
```

OR (React default)

```bash
npm start
```
